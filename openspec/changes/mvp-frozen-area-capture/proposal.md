# Proposal

## Why

minisnap — greenfield-проект: утилита для скриншотов macOS (лёгкий аналог Monosnap) пока не содержит ни строчки кода. Нужна первая работающая вертикаль: пользователь нажимает глобальный хоткей, экран «замораживается», он выделяет область или окно — результат оказывается в буфере обмена и на диске. Эта петля — ядро продукта, ради которого приложение будет запускаться каждый день.

## What Changes

- Создаётся resident-приложение на Rust + objc2/AppKit: один процесс, без иконки в Dock (`LSUIElement`), иконка в меню-баре с меню (capture frozen area с отображением хоткея, preferences, quit).
- Глобальные хоткеи (Carbon-регистрация): `⌘⌥5` — захват «замороженной» области, `⌘⌥0` — открыть последний снимок; обе комбинации переназначаются в настройках.
- По хоткею захвата: снимок дисплея с курсором + список видимых окон в момент T0 → полноэкранный overlay с замороженным кадром → выделение (drag = область, клик по окну = окно целиком, клик по рабочему столу = весь дисплей, Esc = отмена) → кроп из T0-битмапа.
- Overlay-инструментарий: затемнение вне выделения, лупа с увеличенными пикселями кадра и перекрестием (в drag — размер выделения), плоская красная рамка 4pt по периметру экрана как индикатор режима.
- Результат выделения: PNG копируется в буфер обмена и молча сохраняется в `~/Pictures/minisnap` (ретенция «хранить последние 100»).
- Окно Preferences с двумя строками-рекордерами хоткеев; остальные параметры (папка, ретенция) — поля `config.toml` с дефолтами, без UI.
- Обработка разрешения Screen Recording: префлайт, объясняющий диалог, кнопка открытия System Settings.

## Capabilities

### New Capabilities

- `tray-app`: резидентная оболочка — иконка в меню-баре, меню программы, жизненный цикл процесса (агент без Dock-иконки, запуск и выход).
- `global-hotkeys`: глобальные хоткеи — регистрация/перерегистрация, дефолты `⌘⌥5`/`⌘⌥0`, хранение в конфиге, синхронизация отображения в меню.
- `frozen-capture`: захват и выделение на замороженном кадре — снимок и список окон в T0, overlay на дисплее с курсором, правила результата выделения (окно/область/весь дисплей/отмена), лупа, индикатор режима, изоляция остальных дисплеев.
- `capture-output`: вывод результата — копирование в буфер обмена, тихая запись PNG в `~/Pictures/minisnap` с ретенцией, открытие последнего снимка внешним приложением.
- `preferences`: окно настроек с рекордерами хоткеев.
- `screen-recording-permission`: обнаружение и запрос разрешения Screen Recording (TCC).

## Impact

- Новая кодовая база: Rust-крейт (bin), зависимости — `objc2`/`objc2-app-kit`/`objc2-foundation`/`objc2-screen-capture-kit`, `global-hotkey`, `serde`/`toml`; других кодовых баз и API проект не имеет.
- Требования среды: macOS 15+ (Apple Silicon), право Screen Recording; Accessibility не требуется.
- Конфигурация: `~/Library/Application Support/minisnap/config.toml`; файлы снимков: `~/Pictures/minisnap`.
- Вне скоупа MVP: аннотации/редактор, автозапуск при входе, мульти-дисплейный захват, drag-out, загрузки, звук.
