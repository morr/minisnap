# Spec Delta

## REMOVED Requirements

### Requirement: Точки входа — только хоткеи
**Reason**: Требование описывало состав окна настроек «только три комбинации, иных настроек с UI нет»; загрузка на artifacts-сервер добавляет четвёртую комбинацию и два поля (токен, проект). Требование заменяется целиком — состав окна меняется.
**Migration**: Правило состава окна переезжает в ADDED-требование «Состав окна настроек» с четырьмя строками-рекордерами и полями загрузки; механика записи комбинаций без изменений остаётся в требовании «Запись новой комбинации».

## ADDED Requirements

### Requirement: Состав окна настроек
Окно настроек SHALL содержать назначение четырёх комбинаций — «Capture Frozen Area», «Capture and Edit», «Capture and Upload», «Open Latest Image» — и раздел загрузки: строку «Artifacts» с галочкой включения (выключена по умолчанию). Когда галочка включена, под строкой SHALL отображаться поля токена доступа и проекта; когда выключена — поля скрыты. Иных настроек с UI нет. Переключение галочки и изменения полей SHALL применяться и сохраняться в конфигурации сразу.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны четыре строки с названиями действий и их текущими комбинациями, строка «Artifacts» с галочкой; при включённой галочке под ней — поля токена и проекта, при выключенной полей нет

#### Scenario: Включение загрузки
- **WHEN** пользователь включает галочку «Artifacts»
- **THEN** появляются поля токена и проекта, состояние сохраняется в конфигурации и действует сразу

#### Scenario: Выключение загрузки
- **WHEN** пользователь выключает галочку «Artifacts»
- **THEN** поля токена и проекта скрываются, загрузка становится недоступной; введённые значения сохраняются в конфигурации

#### Scenario: Ввод токена
- **WHEN** пользователь вводит или меняет токен в поле настроек
- **THEN** значение сохраняется в конфигурации и действует для последующих загрузок без перезапуска приложения
