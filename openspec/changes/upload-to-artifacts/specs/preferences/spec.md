# Spec Delta

## REMOVED Requirements

### Requirement: Точки входа — только хоткеи
**Reason**: Требование описывало состав окна настроек «только три комбинации, иных настроек с UI нет»; загрузка на artifacts-сервер добавляет четвёртую комбинацию и два поля (токен, проект). Требование заменяется целиком — состав окна меняется.
**Migration**: Правило состава окна переезжает в ADDED-требование «Состав окна настроек» с четырьмя строками-рекордерами и полями загрузки; механика записи комбинаций без изменений остаётся в требовании «Запись новой комбинации».

## ADDED Requirements

### Requirement: Состав окна настроек
Окно настроек SHALL содержать назначение четырёх комбинаций — «Capture Frozen Area», «Capture and Edit», «Capture and Upload», «Open Latest Image» — и настройки загрузки на artifacts-сервер: поле токена доступа и поле проекта. Иных настроек с UI нет. Изменения полей токена и проекта SHALL применяться и сохраняться в конфигурации сразу при вводе.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны четыре строки с названиями действий и их текущими комбинациями, а также поля токена и проекта с текущими значениями

#### Scenario: Ввод токена
- **WHEN** пользователь вводит или меняет токен в поле настроек
- **THEN** значение сохраняется в конфигурации и действует для последующих загрузок без перезапуска приложения
