# Spec Delta

## MODIFIED Requirements

### Requirement: Глобальные хоткеи по умолчанию
Приложение SHALL регистрировать четыре глобальные комбинации клавиш: захват замороженной области — `⌘⌥4`, захват с редактированием — `⌘⌥5`, захват с загрузкой — `⌘⌥6`, открытие последнего снимка — `⌘⌥0`. Комбинации работают при любом активном приложении.

#### Scenario: Дефолтные комбинации после первого запуска
- **WHEN** приложение запущено впервые и настройки не менялись
- **THEN** `⌘⌥4` инициирует захват, `⌘⌥5` инициирует захват с редактированием, `⌘⌥6` инициирует захват с загрузкой, `⌘⌥0` открывает последний снимок

#### Scenario: Срабатывание при чужом активном приложении
- **WHEN** активным является любое приложение, не minisnap
- **THEN** нажатие зарегистрированной комбинации вызывает действие minisnap

## ADDED Requirements

### Requirement: Действие по комбинации захвата с загрузкой
Комбинация «capture & upload» SHALL запускать режим «замороженной области»; после выделения снимок выводится как при обычном захвате и загружается на artifacts-сервер (см. capability `shot-upload`).

#### Scenario: Нажатие комбинации захвата с загрузкой
- **WHEN** пользователь нажимает `⌘⌥6` и завершает выделение
- **THEN** экран «замораживается» и появляется режим выделения, а после выделения снимок сохраняется и загружается на сервер
