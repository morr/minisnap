# Proposal

## Why

Живая проверка `upload-to-artifacts` упала с «upload failed - connection lost»: HTTPS до
`artifacts.spacehubstore.com` из России троттлится и рвётся (РКН). Прямое соединение
провайдера Artifacts не оставляет пользователю способа загрузить снимок, хотя рабочий
обход уже есть и крутится локально: privoxy на `127.0.0.1:8118` — HTTP-прокси, который
форвардит в SOCKS-туннель `ssh -D 5555`. Загрузке нужен способ пойти через такой
локальный прокси.

## What Changes

- Секция провайдера Artifacts получает настройку `proxy` — строку вида
  `scheme://host:port`; пустое значение (дефолт) означает «напрямую, без прокси».
  Поддерживаемые схемы: `http`/`https` (CONNECT-туннель — проверенный NSURLSession путь)
  и `socks5`/`socks5h` (через `kCFNetworkProxiesSOCKS*` — best effort, проверенным путём
  остаётся HTTP-фронт вроде privoxy).
- ArtifactsBackend передаёт разобранный прокси в `connectionProxyDictionary`
  `NSURLSessionConfiguration` (HTTP и HTTPS записи на один host:port); при пустой
  настройке словарь не задаётся — сессия живёт с системными прокси, как сейчас.
- В окне настроек у провайдера появляется третье поле — «Proxy» — наравне с токеном и
  проектом: видно при включённой галочке, сохраняется в конфиг при каждом изменении.
- Конфиг пользователя после применения заполняется его текущим прокси
  (`http://127.0.0.1:8118`), живая проверка загрузки из `upload-to-artifacts`
  (таски 6.1–6.2) продолжается поверх этого change'а.
- Агентский канал не меняется; токен-инвариант (не попадает в журнал и агентский канал)
  не трогается — прокси — не секрет, но в журнал он тоже не выводится.

## Capabilities

### Modified Capabilities

- `shot-upload`: параметры провайдера Artifacts пополняются настройкой прокси (строка
  `scheme://host:port`, пусто — напрямую); загрузка ходит через заданный прокси.
- `preferences`: раздел загрузки — третье поле «Proxy» под галочкой провайдера
  (видно при включённой галочке, сохраняется сразу).

## Impact

- Код: `src/config.rs` (поле `proxy` с дефолтом-пустотой + тесты), `src/upload.rs`
  (разбор строки прокси и `connectionProxyDictionary` у конфигурации сессии + тесты),
  `src/prefs.rs` (третье поле в реестре провайдера), `src/app.rs` (сохранение поля в
  конфиг из окна настроек). Высота окна настроек уже считается по числу полей —
  растёт сама.
- Зависимости не добавляются: ключи прокси — строковые константы CFNetwork
  (`kCFNetworkProxies*`), значения — `NSNumber`/`NSString` из objc2-foundation.
- Change идёт поверх незархивированного `upload-to-artifacts`: дельты к
  `shot-upload` и `preferences` правят требования в формулировках, которые этот
  change вносит; архивация — строго после `upload-to-artifacts`.
