# Spec Delta

## MODIFIED Requirements

### Requirement: Провайдеры загрузки

Настройки SHALL держать включённых провайдеров загрузки картинок — сервисов, куда
отправляется снимок; в этой версии в настройках присутствует один провайдер — Artifacts,
с галочкой включения (выключена по умолчанию). Загрузка SHALL быть доступна только когда
провайдер включён; параметры провайдера Artifacts — адрес сервера (по умолчанию
`https://artifacts.spacehubstore.com`), токен доступа, проект-namespace (по умолчанию
`minisnap`) и прокси. Прокси SHALL задаваться строкой `scheme://host:port`; пустая строка
(значение по умолчанию) означает прямое соединение без прокси. Поддерживаемые схемы —
`http`/`https` и `socks5`/`socks5h`; запросы к серверу SHALL ходить через заданный прокси.
Токен и проект SHALL редактироваться в окне настроек (появляются при включении
провайдера) вместе с полем прокси; адрес сервера настраивается только правкой
конфигурационного файла.

#### Scenario: Первый запуск без настройки
- **WHEN** приложение запущено впервые и настройки загрузки не менялись
- **THEN** провайдер Artifacts выключен, прокси пуст (загрузка ходит напрямую, как
  решают системные настройки), загрузка недоступна до включения и ввода токена

#### Scenario: Включение провайдера
- **WHEN** пользователь включил галочку провайдера и ввёл токен
- **THEN** загрузка работает без перезапуска приложения, настройки сохраняются между
  запусками

#### Scenario: Загрузка через локальный прокси
- **WHEN** провайдер включён, в поле прокси задан локальный HTTP-прокси
  (`http://127.0.0.1:8118`), и пользователь запускает загрузку
- **THEN** запрос к серверу идёт через этот прокси, публичный URL возвращается как при
  прямом соединении

#### Scenario: Прокси очищен
- **WHEN** пользователь стёр значение поля прокси
- **THEN** последующие загрузки ходят напрямую (системные настройки прокси), без
  перезапуска приложения
