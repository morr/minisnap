# Spec Delta

## MODIFIED Requirements

### Requirement: Состав окна настроек

Окно настроек SHALL содержать назначение четырёх комбинаций — «Capture Frozen Area»,
«Capture and Edit», «Capture and Upload», «Open Latest Image» — и раздел загрузки:
строку «Artifacts» с галочкой включения (выключена по умолчанию). Когда галочка
включена, под строкой SHALL отображаться поля токена доступа, проекта и прокси; когда
выключена — поля скрыты. Иных настроек с UI нет. Переключение галочки и изменения полей
SHALL применяться и сохраняться в конфигурации сразу. Поле прокси — строка
`scheme://host:port`; пустое значение означает прямое соединение.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны четыре строки с названиями действий и их текущими комбинациями,
  строка «Artifacts» с галочкой; при включённой галочке под ней — поля токена, проекта
  и прокси, при выключенной полей нет

#### Scenario: Включение загрузки
- **WHEN** пользователь включает галочку «Artifacts»
- **THEN** появляются поля токена, проекта и прокси, состояние сохраняется в
  конфигурации и действует сразу

#### Scenario: Выключение загрузки
- **WHEN** пользователь выключает галочку «Artifacts»
- **THEN** поля токена, проекта и прокси скрываются, загрузка становится недоступной;
  введённые значения сохраняются в конфигурации

#### Scenario: Ввод токена
- **WHEN** пользователь вводит или меняет токен в поле настроек
- **THEN** значение сохраняется в конфигурации и действует для последующих загрузок без
  перезапуска приложения

#### Scenario: Ввод прокси
- **WHEN** пользователь вводит или меняет адрес прокси в поле настроек
- **THEN** значение сохраняется в конфигурации, и последующие загрузки ходят через этот
  прокси (или напрямую, если поле пусто) без перезапуска приложения
