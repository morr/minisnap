# Spec Delta

## MODIFIED Requirements

### Requirement: Точки входа — только хоткеи
Окно настроек в этой версии SHALL содержать только назначение трёх комбинаций: «Capture Frozen Area», «Capture and Edit» и «Open Latest Image». Иных настроек с UI нет.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны три строки с названиями действий и их текущими комбинациями
