# Tasks

## 1. Документ и команды (модуль `editor`, чистая логика без UI)

- [x] 1.1 Модуль `editor`: enum'ы `Element` (arrow/rect/line/pen/text/callout/blur) и `Command` (add/delete/move/move-point/edit-text/crop/resize), `EditorDoc` с базовым кадром, списком элементов и журналом; `apply`/`undo`/`redo` через перепроигрывание префикса от оригинала; юнит-тесты: последовательность add+move+delete воспроизводится replay'ем, undo/redo возвращают точно предыдущее состояние
- [x] 1.2 Crop/Resize как команды: мутация базового кадра и трансформация координат существующих элементов; юнит-тесты на synthetic-кадре: после Crop элементы сдвинуты на −origin, после Resize отмасштабированы, undo возвращает исходные координаты
- [x] 1.3 Рендер композита в CGContext (кадр + элементы, без служебной графики): клин-стрелка (перпендикуляры к оси, хвост ~25% толщины), прямоугольник, линия, pen; юнит-тест: рендер синтетического кадра с элементами даёт валидный CGImage ожидаемого размера
- [x] 1.4 Зависимость `objc2-core-text`; рендер текста в CGContext с белой обводкой (проход stroke + проход fill), измерение bbox текста; юнит-тест: измерение непустого текста даёт положительные размеры
- [x] 1.5 Блюр: пикселизация региона кадра (downscale в маленький bitmap context, upscale с interpolation none); юнит-тест: после пикселизации область региона отличается от оригинала, кадр вне региона не меняется
- [x] 1.6 Хит-тест элементов с допуском (расстояние до отрезка/оси стрелки/контура прямоугольника, bbox для текста/блюра, отдельные зоны концов стрелки/линии/коллаута); юнит-тесты на попадание/промах и различение конца от тела
