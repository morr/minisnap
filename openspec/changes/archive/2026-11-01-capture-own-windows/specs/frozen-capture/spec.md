# Spec Delta — frozen-capture

## MODIFIED Requirements

### Requirement: Клик по окну — окно целиком

Клик без перетаскивания SHALL захватывать целиком окно под курсором. Границы окна определяются по списку видимых окон T0; служебные слои System UI исключаются. Окна самого minisnap, видимые в момент снимка T0, участвуют в клик-захвате наравне с окнами других приложений.

#### Scenario: Клик по окну приложения
- **WHEN** пользователь кликает по видимой части окна приложения
- **THEN** результатом является полный снимок этого окна, включая части, скрытые за пределами клика

#### Scenario: Клик по окну minisnap
- **WHEN** пользователь кликает по видимому окну самого minisnap (окну редактора снимка или окну настроек)
- **THEN** результатом является полный снимок этого окна, как для окна любого другого приложения
