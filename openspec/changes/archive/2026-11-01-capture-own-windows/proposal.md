# Proposal

## Why

Клик-захват окна не работает для собственных окон minisnap: спека `frozen-capture` требует исключать «окна самого minisnap» из списка окон T0, поэтому клик по открытому окну редактора или настроек не находит окно и проваливается в fallback «клик мимо окон» — захватывается весь дисплей вместо окна. Наблюдаемое поведение соответствует букве спеки, поэтому правится сама спека; замороженный кадр собственные окна уже содержит (фильтр захвата дисплея ничего не исключает), так что правка сводится к сужению исключения в спеке и точечной правке фильтра в коде.

## What Changes

- Спека `frozen-capture`, требование «Клик по окну — окно целиком»: блочное исключение «окна самого minisnap» убирается — собственные окна приложения (редактор снимка, окно настроек) становятся обычными целями клик-захвата; исключение остаётся только для служебных слоёв System UI.
- Код: `visible_windows` в `src/capture.rs` перестаёт выкидывать окна по собственному pid — список окон T0 фильтруется только общими условиями видимости (layer 0, on-screen, есть владеющее приложение).
- Клик-захват перестаёт доверять списку окон T0 как истине: ScreenCaptureKit отстаёт от свежесозданных окон, а порядок списка не обязан совпадать с композитором, поэтому клик по видимому окну промахивался и падал на случайное крупное перекрывающее окно (Chrome, Finder — «весь экран»/«пол экрана»). Победитель хит-теста теперь проверяется отрисовкой окна и сравнением с замороженным кадром в точке клика; при промахе список перезапрашивается свежим.
- Отдельная защита «захвата самого режима захвата» не вводится: оверлей и вуали создаются уже после снимка T0 и в список окон не попадают.
- Скил `minisnap-capture` обновляется в этом же change (инвариант про состав списка окон T0 и механику клика).

### Modified Capabilities

- `frozen-capture`: требование «Клик по окну — окно целиком» — собственные окна minisnap участвуют в клик-захвате наравне с окнами других приложений; добавлен сценарий «Клик по окну minisnap».

## Impact

- Код: `src/capture.rs` (`visible_windows` — удаление own-pid проверки; новый `resolve_click_target` — кандидаты клика, свежий перезапрос списка, рендер-проверка), `src/overlay.rs` (клик-путь зовёт `resolve_click_target`). Хит-тест и кроп (`topmost_window_at`, `window_frame_to_pixel_rect`) не меняются.
- Спека: `openspec/specs/frozen-capture/spec.md` — дельта по требованию «Клик по окну — окно целиком» (финальная синхронизация текста со спекой — на этапе archive).
- Скил: `.zcode/skills/minisnap-capture/SKILL.md`.
- Разрешения (Screen Recording / Accessibility) не затрагиваются; поведение протяжки и отмены не меняется.
