# Spec Delta

## ADDED Requirements

### Requirement: Показ без кадра прошлого снимка
При показе оверлея, включая повторные запуски режима за жизнь процесса, дисплей SHALL накрываться кадром T0 текущего запуска с первого отображаемого кадра. Содержимое оверлея прошлого запуска не SHALL появляться на экране ни на один кадр анимации.

#### Scenario: Повторный запуск режима
- **WHEN** пользователь запускает захват повторно после завершения предыдущего режима в том же запуске приложения
- **THEN** оверлей с первого момента показа отображает кадр T0 текущего запуска, кадр прошлого снимка не мелькает

#### Scenario: Первый запуск режима
- **WHEN** пользователь запускает захват впервые после старта приложения
- **THEN** оверлей отображает кадр T0 текущего запуска, поведение не отличается от повторного запуска
