# Spec Delta

## ADDED Requirements

### Requirement: Заголовок окна с меткой чекаута

Окно настроек SHALL иметь заголовок «Preferences — <метка>», где метка выводится из пути исполняемого файла: путь под `.worktrees/<branch>/…` даёт метку `<branch>`, любой иной путь — метку `main`.

#### Scenario: Заголовок в worktree-инстансе

- **WHEN** окно настроек открыто инстансом, запущенным из worktree
- **THEN** заголовок окна — «Preferences — <ветка>»

#### Scenario: Заголовок в основном инстансе

- **WHEN** окно настроек открыто инстансом из основного чекаута
- **THEN** заголовок окна — «Preferences — main»
