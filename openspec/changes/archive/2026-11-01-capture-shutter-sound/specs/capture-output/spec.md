# Spec Delta

## ADDED Requirements

### Requirement: Звук затвора при снимке
При завершении выделения приложение SHALL воспроизводить короткий звук
затвора камеры — тот же, что играет системная утилита скриншотов macOS, —
один раз на снимок. При отмене захвата звук SHALL NOT воспроизводиться.
Если системный звук скриншотов выключен ключом `disable-sound` домена
`com.apple.screencapture`, звук SHALL NOT воспроизводиться. Если системный
файл звука недоступен, снимок SHALL выполняться как обычно — молча, без
сообщения об ошибке.

#### Scenario: Успешный снимок
- **WHEN** выделение завершено и системный звук скриншотов не выключен
- **THEN** в момент завершения выделения воспроизводится звук затвора камеры, один раз

#### Scenario: Системный звук выключен
- **WHEN** ключ `disable-sound` домена `com.apple.screencapture` установлен
  в `true` и выделение завершено
- **THEN** звук не воспроизводится, снимок сохраняется и копируется как обычно

#### Scenario: Отмена захвата
- **WHEN** захват отменён (Esc, клик по затемнению соседнего дисплея,
  смена конфигурации дисплеев)
- **THEN** звук не воспроизводится

#### Scenario: Несколько дисплеев
- **WHEN** снимок сделан при нескольких подключённых дисплеях
- **THEN** звук воспроизводится один раз на снимок, а не по разу на каждый дисплей

#### Scenario: Звуковой файл недоступен
- **WHEN** системный файл звука затвора не найден на данной версии macOS
- **THEN** снимок выполняется как обычно, без звука и без сообщения об ошибке
