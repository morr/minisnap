# Spec Delta

## Purpose

Обращение с разрешением Screen Recording: проверка при старте, объясняющий диалог и корректное поведение, пока разрешение не выдано.

## ADDED Requirements

### Requirement: Проверка при запуске
При запуске приложение SHALL проверять наличие разрешения Screen Recording. Если разрешение не выдано, приложение показывает диалог с объяснением, зачем нужно разрешение, и кнопкой открытия настроек приватности System Settings.

#### Scenario: Первый запуск без разрешения
- **WHEN** приложение запущено и разрешение Screen Recording не выдано
- **THEN** появляется объясняющий диалог с кнопкой перехода к System Settings

#### Scenario: Разрешение выдано
- **WHEN** приложение запущено и разрешение выдано
- **THEN** диалог не показывается, приложение работает штатно

### Requirement: Захват без разрешения невозможен
Если разрешение Screen Recording не выдано, нажатие хоткея захвата MUST NOT создавать снимок; вместо этого приложение показывает объясняющий диалог.

#### Scenario: Хоткей без разрешения
- **WHEN** разрешение не выдано и пользователь нажимает хоткей захвата
- **THEN** режим выделения не запускается, показывается объясняющий диалог

### Requirement: Продолжение после выдачи разрешения
После выдачи разрешения в System Settings приложение SHALL подхватывать его без перезапуска (или после повторного запуска — с минимальными действиями пользователя).

#### Scenario: Разрешение выдано после диалога
- **WHEN** пользователь выдал разрешение из открытых System Settings
- **THEN** захват начинает работать без переустановки приложения
