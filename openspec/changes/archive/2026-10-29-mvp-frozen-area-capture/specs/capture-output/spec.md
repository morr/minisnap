# Spec Delta

## Purpose

Вывод результата захвата: копирование снимка в буфер обмена, тихое сохранение PNG-файлов в пользовательскую папку с ретенцией и открытие последнего снимка.

## ADDED Requirements

### Requirement: Копирование в буфер обмена
По завершении выделения приложение SHALL помещать снимок в формате PNG в буфер обмена так, что вставка в другие приложения даёт изображение.

#### Scenario: Вставка в другое приложение
- **WHEN** выделение завершено и пользователь вставляет из буфера в другое приложение
- **THEN** вставляется только что сделанный снимок

### Requirement: Тихое сохранение в папку
Каждый снимок SHALL автоматически сохраняться файлом PNG в папку `~/Pictures/minisnap`. Папка и родительские каталоги создаются при необходимости; сохранение происходит молча, без диалогов и уведомлений.

#### Scenario: Первый снимок создаёт папку
- **WHEN** папки `~/Pictures/minisnap` не существует и выделение завершено
- **THEN** папка создаётся и в ней появляется файл снимка

#### Scenario: Имя файла по времени
- **WHEN** выполняются два последовательных снимка
- **THEN** файлы получают различные имена, упорядочиваемые по времени создания

### Requirement: Ретенция снимков
Приложение SHALL хранить не более 100 последних снимков в папке `~/Pictures/minisnap`; при сохранении нового снимка старые сверх лимита удаляются.

#### Scenario: Снимок сверх лимита
- **WHEN** в папке уже 100 снимков и сохраняется новый
- **THEN** самый старый файл удаляется, общее количество остаётся 100

### Requirement: Открытие последнего снимка
Действие «открыть последний снимок» SHALL открывать файл самого свежего снимка из `~/Pictures/minisnap` приложением, сопоставленным с PNG по умолчанию. Если снимков нет, действие ничего не открывает.

#### Scenario: Открытие через хоткей
- **WHEN** в папке есть снимки и пользователь нажимает комбинацию открытия
- **THEN** самый свежий снимок открывается приложением по умолчанию

#### Scenario: Папка пуста
- **WHEN** в папке нет файлов и пользователь нажимает комбинацию открытия
- **THEN** не открывается ничего и не показывается ошибок
