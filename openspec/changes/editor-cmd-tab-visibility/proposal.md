# Proposal

## Why

minisnap живёт как menu-bar-агент (`NSApplicationActivationPolicy::Accessory`), а macOS показывает в переключателе приложений cmd+tab только Regular-приложения. Из-за этого открытое окно редактора — самое нужное окно утилиты — недостижимо с клавиатуры: пользователь не может переключиться на него по cmd+tab, как на окна обычных приложений.

## What Changes

- Пока окно редактора видно на экране, приложение динамически переключается в Regular-политику: попадает в cmd+tab и получает иконку в Dock (неотъемлемое следствие Regular-политики — скрыть иконку, оставшись в переключателе, macOS не позволяет).
- Когда окно редактора скрыто любым путём (красная кнопка, Esc, ⌘Q/⌘W, жёлтая кнопка, агентский `CloseEditor`), приложение возвращается в режим агента: исчезает из cmd+tab и из Dock.
- Запуск остаётся агентским без изменений: при старте редактора нет, иконки в Dock и записи в cmd+tab нет.
- `GET /state` агент-канала добавляет текущую политику активации — наблюдаемое состояние для live-проверки изменения.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `tray-app`: требование «Агент без Dock-иконки» уточняется — агентность формулируется как режим запуска и режим без открытого редактора; добавляется требование о видимости в переключателе приложений при открытом редакторе.
- `shot-editor`: требование «Окно редактора» — фразы «приложение — accessory без иконки в доке» и «иконки в доке не появляются» заменяются на поведение с временной Dock-иконкой при видимом редакторе (сценарии «Миниатюризация и зум скрыты», «Жёлтая кнопка прячет окно»).
- `agent-control`: требование «Состояние приложения» — `/state` SHALL возвращать текущую политику активации.

## Impact

- `src/app.rs` — переключение политики активации при открытии редактора и синхронизация при скрытии окна; точка активации `editorWindowToFront:`.
- `src/editor_window.rs` — единая воронка скрытия окна: пути миниатюризации переводятся на `close`, чтобы все пути скрытия проходили через один хук (`windowWillClose:`).
- `src/agent_proto.rs`, `src/agent_server.rs`, `src/bin/minisnap-mcp.rs` — поле политики активации в ответе `/state`.
- Новых зависимостей нет; переключение в рантайме — штатная `NSApplication.setActivationPolicy`.
