# Spec Delta

## MODIFIED Requirements

### Requirement: Агент без Dock-иконки
При запуске приложение SHALL работать как агент: без иконки в Dock, без записи в переключателе приложений cmd+tab и без главного окна. Пока окно редактора не видно на экране, приложение SHALL оставаться агентом. Видимому окну редактора соответствует временное Regular-состояние по требованию «Видимость редактора в переключателе приложений».

#### Scenario: Запуск приложения
- **WHEN** приложение запущено
- **THEN** в Dock не появляется иконка приложения, на экране нет окон, приложения нет в cmd+tab

#### Scenario: Возврат в агент после скрытия редактора
- **WHEN** окно редактора было видно и скрылось любым из путей закрытия
- **THEN** приложение снова агент: иконки в Dock нет, в переключателе cmd+tab его нет

## ADDED Requirements

### Requirement: Видимость редактора в переключателе приложений
Пока окно редактора видно на экране, приложение SHALL присутствовать в переключателе приложений cmd+tab как обычное (Regular) приложение, с иконкой в Dock. Выбор minisnap в cmd+tab SHALL поднимать окно редактора и передавать ему фокус. Скрытие окна любым из путей закрытия (Esc, ⌘Q, ⌘W, красная или жёлтая системная кнопка, агентский CloseEditor) возвращает приложение в агентский режим.

#### Scenario: Открытый редактор виден в cmd+tab
- **WHEN** окно редактора показано на экране
- **THEN** minisnap присутствует в переключателе cmd+tab, в Dock видна иконка приложения

#### Scenario: Переключение на редактор из cmd+tab
- **WHEN** активно другое приложение, окно редактора открыто, и пользователь выбирает minisnap в cmd+tab
- **THEN** окно редактора становится активным и поднятым наверх

#### Scenario: Закрытый редактор отсутствует в cmd+tab
- **WHEN** окно редактора скрыто любым из путей закрытия
- **THEN** приложения нет в переключателе cmd+tab, иконки в Dock нет
