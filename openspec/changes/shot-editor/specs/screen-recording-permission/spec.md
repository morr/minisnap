# Spec Delta

## MODIFIED Requirements

### Requirement: Проверка при запуске
При запуске приложение SHALL проверять наличие разрешения Screen Recording. Если разрешение не выдано, приложение SHALL зарегистрировать запрос разрешения у системы (запрос делает текущую сборку видимой в панели Screen Recording и показывает системный промпт с переходом в System Settings). Собственный объясняющий диалог при старте SHALL NOT показываться — он дублирует системный промпт.

#### Scenario: Первый запуск без разрешения
- **WHEN** приложение запущено и разрешение Screen Recording не выдано
- **THEN** появляется системный промпт выдачи разрешения, объясняющий диалог приложения не показывается

#### Scenario: Разрешение выдано
- **WHEN** приложение запущено и разрешение выдано
- **THEN** никакие диалоги не показываются, приложение работает штатно
