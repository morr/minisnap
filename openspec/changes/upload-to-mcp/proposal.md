# Proposal

## Why

Загрузка снимка на artifacts-сервер доступна только кнопкой Upload в редакторе; change `upload-to-artifacts` сознательно отложил программный запуск через агентский канал («возможный следующий change»). Сессии, управляющие minisnap через MCP, не могут довести сценарий до конца: снять и открыть снимок они могут, а выложить — нет.

## What Changes

- Новое действие `AgentAction::Upload {}` в агентском канале: загружает файл снимка, открытого в редакторе, тем же кодовым путём, что кнопка Upload (`handle_upload_request`): тот же бекенд из конфига, то же состояние «загрузка» у кнопки, тот же ответ через `MainJob::UploadFinished`.
- Статусная модель действия по конвенциям канала: провайдер не настроен (выключен или токен пуст) → `rejected` с причиной и без модального диалога на экране пользователя (как `agent_capture` с разрешением); нет редактора или снимка → `rejected`; загрузка уже в полёте → `rejected`; запрос ушёл → `initiated` с указанием поллить `/state`.
- `EditorState` в `/state` дополняется полем `uploading` (идёт ли загрузка), чтобы агент поллил завершение из состояния, а не из скриншотов.
- Строка успеха в журнале (`/log`) дополнительно несёт публичный URL — результат, который агент может прочитать из канала.
- Описание инструмента `action` MCP-моста и раздел про minisnap MCP в рабочем `AGENTS.md` дополняются формой `{"Upload":{}}` и полем `uploading` состояния.
- Инвариант секретов сохраняется: токен по-прежнему не попадает ни в журнал, ни в агентский канал; результаты действия — статусы и публичный URL.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `agent-control`: дельта к трём требованиям — «Действия уровня приложения» (новое действие Upload и его статусная модель), «Состояние приложения» (поле `uploading` документа редактора), «MCP-сервер minisnap-mcp» (форма `{"Upload":{}}` в описании `action`).

## Impact

- Код: `src/agent_proto.rs` (вариант `Upload`), `src/app.rs` (обработка действия, выделение общего хвоста кнопки и агента, строка журнала с URL), `src/editor_window.rs` (геттеры `shot_path`/`is_uploading`, поле в `agent_state`), `src/bin/minisnap-mcp.rs` (только описания инструментов — маршрутизация `action` уже прозрачная), `AGENTS.md` (раздел про MCP).
- Зависимостей нет: сетевой транспорт, конфиг и prefs не меняются.
- Риски нет: действие идёт по уже живому пути загрузки; пользовательские поверхности (кнопка, меню, диалоги) не меняются.
