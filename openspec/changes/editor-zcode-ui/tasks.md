Проверка: руками — close закрывает окно в трей, зелёная разворачивает на весь экран и возвращает, жёлтая прячет окно; «открыть последний» после жёлтой показывает окно снова; ◄/► листают.
- [ ] 1.3 Собрать вертикальный стек контролов под верхней строкой: свотч цвета → вертикальный слайдер толщины → горизонтальный разделитель → девять инструментов тремя группами с увеличенным интервалом, выравнивание по центру колонки, размеры видов только на autolayout (констрейнты 28×28, intrinsic у слайдера), вычислить и хранить минимальную высоту окна вместо `min_width`. Проверка: `cargo build` чист; колонка не схлопнута (свотч — диск 18 pt, слайдер виден), hover-плашка появляется на каждой кнопке и уходит при выходе курсора.
