# Proposal

## Why

Почти каждая новая задача в проекте — `/opsx:propose`, `/opsx:apply`, разовая правка — начинается с одного и того же: агент исследует код, чтобы понять, где живёт захват, как устроен редактор, какие конвенции координат и где границы модулей. Кодовая база — ~9 тысяч строк Rust в 15 модулях плюс 7 спецификаций, и это исследование повторяется на каждой задаче, сжигая время и токены. Доменные скилы в `.zcode/skills/` дадут агентам готовую карту функционала и логики: скил загружается по триггеру и заменяет первичное чтение кода, оставляя код для точечной проверки деталей.

## What Changes

- Пять новых проектных скилов в `.zcode/skills/` (по скилу на домен плюс общий слой):
  - `minisnap-architecture` — общий слой: карта модулей, сквозной поток данных (хоткей → оверлей → захват → вывод → редактор), сквозные конвенции — системы координат, владение `CGImage`, objc2/`MainThreadMarker`-паттерны, контракт заморозки T0;
  - `minisnap-shell` — жизненный цикл приложения и трей, конфигурация и её миграции, окно настроек, глобальные хоткеи, разрешения Screen Recording / Accessibility;
  - `minisnap-capture` — ScreenCaptureKit, заморозка кадра в момент T0, полноэкранный оверлей, выделение области и клик по окну, лупа, вуаль соседних дисплеев;
  - `minisnap-output` — копирование в буфер, тихое сохранение PNG, схема имён файлов, ретенция, листинг снимков;
  - `minisnap-editor` — окно редактора, модель элементов, рендер (стрелка, блюр, композит), hit-testing, сессии правок и undo в `/tmp/.minisnap/`, кроп и ресайз.
- У каждого скила — frontmatter с триггер-описанием, покрывающим типовые формулировки задач его домена; глубокая детализация выносится в `references/`, загружаемые по необходимости.
- Общий слой живёт в `minisnap-architecture` как отдельный скил со своим триггером (ориентация, планирование, кросс-доменные задачи); доменные скилы ссылаются только на него, не друг на друга.
- В AGENTS.md добавляется правило синхронизации: правка, меняющая поведение модуля, обновляет и соответствующий скил.

## Capabilities

### New Capabilities

- `agent-domain-skills`: доменные скилы для агентов — состав и границы доменов, требования к покрытию и триггер-описаниям, бюджеты размера с прогрессивной загрузкой, единый общий слой и правило синхронизации с кодом.

### Modified Capabilities

нет — поведение приложения не меняется.

## Impact

- Новые файлы: `.zcode/skills/minisnap-{architecture,shell,capture,output,editor}/` (SKILL.md и references). Правка: `AGENTS.md` (раздел о доменных скилах и правиле их обновления).
- Продуктовый код, зависимости, API приложения — без изменений.
- Язык скилов — русский (проза) с английскими идентификаторами и путями, как в спеках проекта.
