# global-hotkeys Specification

## Purpose

Глобальные комбинации клавиш minisnap: срабатывают в любом приложении, назначаются по умолчанию и переназначаются пользователем с сохранением между запусками.

## Requirements

### Requirement: Два глобальных хоткея по умолчанию
Приложение SHALL регистрировать две глобальные комбинации клавиш: захват замороженной области — `⌘⌥5`, открытие последнего снимка — `⌘⌥0`. Комбинации работают при любом активном приложении.

#### Scenario: Дефолтные комбинации после первого запуска
- **WHEN** приложение запущено впервые и настройки не менялись
- **THEN** `⌘⌥5` инициирует захват, `⌘⌥0` открывает последний снимок

#### Scenario: Срабатывание при чужом активном приложении
- **WHEN** активным является любое приложение, не minisnap
- **THEN** нажатие зарегистрированной комбинации вызывает действие minisnap

### Requirement: Действие по комбинации захвата
Комбинация захвата SHALL запускать режим «замороженной области» на дисплее с курсором (см. capability `frozen-capture`).

#### Scenario: Нажатие комбинации захвата
- **WHEN** пользователь нажимает `⌘⌥5`
- **THEN** экран «замораживается» и появляется режим выделения

### Requirement: Действие по комбинации открытия последнего снимка
Комбинация открытия SHALL открывать самый свежий снимок приложением по умолчанию (см. capability `capture-output`).

#### Scenario: Нажатие комбинации открытия
- **WHEN** пользователь нажимает `⌘⌥0` и в папке снимков есть файлы
- **THEN** самый свежий снимок открывается приложением по умолчанию

### Requirement: Немедленная перерегистрация
После смены комбинации в настройках приложение SHALL применять новую комбинацию немедленно; прежняя комбинация перестаёт вызывать действие.

#### Scenario: Смена комбинации
- **WHEN** пользователь записал новую комбинацию захвата в настройках
- **THEN** новая комбинация инициирует захват, прежняя — нет

### Requirement: Сохранение между запусками
Пользовательские комбинации SHALL сохраняться в конфигурации и восстанавливаться при следующем запуске приложения.

#### Scenario: Перезапуск приложения
- **WHEN** пользователь назначил свои комбинации и перезапустил приложение
- **THEN** действуют назначенные комбинации, а не дефолтные
