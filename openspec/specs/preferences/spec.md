# preferences Specification

## Purpose

Окно настроек minisnap: назначение глобальных комбинаций клавиш через поля-рекордеры в нативном стиле macOS.

## Requirements

### Requirement: Открытие окна настроек
Пункт меню «Preferences» SHALL открывать окно настроек; повторное открытие при уже открытом окне фокусирует существующее окно.

#### Scenario: Открытие из меню
- **WHEN** пользователь выбирает «Preferences» в меню иконки
- **THEN** открывается окно настроек

#### Scenario: Повторное открытие
- **WHEN** окно настроек уже открыто и пользователь снова выбирает «Preferences»
- **THEN** новое окно не создаётся, существующее выходит на передний план

### Requirement: Точки входа — только хоткеи
Окно настроек в этой версии SHALL содержать только назначение трёх комбинаций: «Capture Frozen Area», «Capture and Edit» и «Open Latest Image». Иных настроек с UI нет.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны три строки с названиями действий и их текущими комбинациями

### Requirement: Запись новой комбинации
Клик по полю комбинации SHALL переводить поле в режим записи; следующее нажатие комбинации клавиш фиксируется как новое значение. Комбинация SHALL содержать хотя бы один модификатор: нажатие клавиши без модификаторов (кроме отменяющей записи Esc) не фиксируется и не завершает запись. Нажатие Esc в режиме записи отменяет запись, значение не меняется.

#### Scenario: Запись комбинации
- **WHEN** пользователь кликает поле, нажимает новую комбинацию с модификаторами и отпускает
- **THEN** поле показывает новую комбинацию, она немедленно действует глобально и в меню

#### Scenario: Клавиша без модификаторов
- **WHEN** поле в режиме записи и пользователь нажимает клавишу без модификаторов (не Esc)
- **THEN** нажатие не фиксируется, поле остаётся в режиме записи

#### Scenario: Отмена записи
- **WHEN** поле в режиме записи и пользователь нажимает Esc
- **THEN** поле выходит из режима записи, прежняя комбинация сохраняется
