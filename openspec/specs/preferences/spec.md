# preferences Specification

## Purpose

Окно настроек minisnap: назначение глобальных комбинаций клавиш через поля-рекордеры в нативном стиле macOS.

## Requirements

### Requirement: Открытие окна настроек
Пункт меню «Preferences» SHALL открывать окно настроек; повторное открытие при уже открытом окне фокусирует существующее окно.

#### Scenario: Открытие из меню
- **WHEN** пользователь выбирает «Preferences» в меню иконки
- **THEN** открывается окно настроек

#### Scenario: Повторное открытие
- **WHEN** окно настроек уже открыто и пользователь снова выбирает «Preferences»
- **THEN** новое окно не создаётся, существующее выходит на передний план

### Requirement: Состав окна настроек

Окно настроек SHALL содержать назначение четырёх комбинаций — «Capture Frozen Area»,
«Capture and Edit», «Capture and Upload», «Open Latest Image» — и раздел загрузки:
строку «Artifacts» с галочкой включения (выключена по умолчанию). Когда галочка
включена, под строкой SHALL отображаться поля токена доступа, проекта и прокси; когда
выключена — поля скрыты. Иных настроек с UI нет. Переключение галочки и изменения полей
SHALL применяться и сохраняться в конфигурации сразу. Поле прокси — строка
`scheme://host:port`; пустое значение означает прямое соединение.

#### Scenario: Состав окна
- **WHEN** окно настроек открыто
- **THEN** в нём видны четыре строки с названиями действий и их текущими комбинациями,
  строка «Artifacts» с галочкой; при включённой галочке под ней — поля токена, проекта
  и прокси, при выключенной полей нет

#### Scenario: Включение загрузки
- **WHEN** пользователь включает галочку «Artifacts»
- **THEN** появляются поля токена, проекта и прокси, состояние сохраняется в
  конфигурации и действует сразу

#### Scenario: Выключение загрузки
- **WHEN** пользователь выключает галочку «Artifacts»
- **THEN** поля токена, проекта и прокси скрываются, загрузка становится недоступной;
  введённые значения сохраняются в конфигурации

#### Scenario: Ввод токена
- **WHEN** пользователь вводит или меняет токен в поле настроек
- **THEN** значение сохраняется в конфигурации и действует для последующих загрузок без
  перезапуска приложения

#### Scenario: Ввод прокси
- **WHEN** пользователь вводит или меняет адрес прокси в поле настроек
- **THEN** значение сохраняется в конфигурации, и последующие загрузки ходят через этот
  прокси (или напрямую, если поле пусто) без перезапуска приложения

### Requirement: Запись новой комбинации
Клик по полю комбинации SHALL переводить поле в режим записи; следующее нажатие комбинации клавиш фиксируется как новое значение. Комбинация SHALL содержать хотя бы один модификатор: нажатие клавиши без модификаторов (кроме отменяющей записи Esc) не фиксируется и не завершает запись. Нажатие Esc в режиме записи отменяет запись, значение не меняется.

#### Scenario: Запись комбинации
- **WHEN** пользователь кликает поле, нажимает новую комбинацию с модификаторами и отпускает
- **THEN** поле показывает новую комбинацию, она немедленно действует глобально и в меню

#### Scenario: Клавиша без модификаторов
- **WHEN** поле в режиме записи и пользователь нажимает клавишу без модификаторов (не Esc)
- **THEN** нажатие не фиксируется, поле остаётся в режиме записи

#### Scenario: Отмена записи
- **WHEN** поле в режиме записи и пользователь нажимает Esc
- **THEN** поле выходит из режима записи, прежняя комбинация сохраняется

### Requirement: Заголовок окна с меткой чекаута

Окно настроек SHALL иметь заголовок «Preferences — <метка>», где метка выводится из пути исполняемого файла: путь под `.worktrees/<branch>/…` даёт метку `<branch>`, любой иной путь — метку `main`.

#### Scenario: Заголовок в worktree-инстансе

- **WHEN** окно настроек открыто инстансом, запущенным из worktree
- **THEN** заголовок окна — «Preferences — <ветка>»

#### Scenario: Заголовок в основном инстансе

- **WHEN** окно настроек открыто инстансом из основного чекаута
- **THEN** заголовок окна — «Preferences — main»
